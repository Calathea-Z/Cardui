# CSV import UX

Date: October 4, 2026

## Increment

Rebuilt the import sheet as a sequence: choose the account and file, map
columns, preview and choose rows, then import. Preview, column mapping,
duplicate detection, opening-date and future-date checks, and batch undo stay
as approved. Phone and desktop layout stay in Phase 6 item 4. The on-screen
name is still Tortoise. Zach approved this increment on October 4, 2026.
Phase 2 item 1 is next.

## Changes

- The sheet shows the four steps and only the current step's fields.
- Continue on the first step requires an account and a CSV that has been
  read. The file still has to be UTF-8 `.csv`, at most 1 MB.
- Map columns says why it is there: which column becomes the date, the
  name, and the amount. The column names from the file are already selected.
  It shows a sample of the file. Column choices say which column holds the
  date, name, amount, category, and notes.
  A separate group says how dates and amounts are written: one amount column
  or debit and credit, month-first or day-first, and whether a positive amount
  is money out or money in. Preview checks the mapping, then opens the row
  step. Going back without changing the mapping keeps that preview.
- Ready rows start checked. A duplicate stays unchecked until it is included.
  A row that needs a fix cannot be included. The import step states how many
  rows will be imported, how many of those are duplicates that were checked,
  and how many rows are left out.
- After import, undo for that batch is on the same step. Undo for any open
  batch is on the first step. Undo still archives the batch. Import another
  file returns to the first step.
- Back keeps the account, file, mapping, and row choices.
