# 0008. Forward-looking charts live on Plan

Status: Accepted
Date: 2026-10-07
Updated: 2026-10-08

## Context

The first Plan page showed the cash-flow recovery report as text. Zach
asked where charts belong. Home already shows what happened: net worth,
monthly activity, and spending by category.

## Decision

Charts that look forward live on Plan: balances falling, minimums
removed, breathing room, and the cash outlook. Home keeps the history.

## Consequences

A forecast on Home or Accounts points to Plan instead of drawing a second
copy. The page shape is in [`docs/design/plan-page.md`](../design/plan-page.md).
